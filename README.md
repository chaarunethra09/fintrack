# FinTrack - Personal Finance Tracker

A desktop app to track income and expenses, built with Python, Tkinter and SQLite.

## Features
- Add income and expense transactions
- Input validation (title required, positive amount)
- Transactions shown in a scrollable table
- Live Income, Expense and Balance totals
- Data saved permanently in fintrack.db

## Technologies
- Python 3
- Tkinter (GUI)
- SQLite3 (database)

## How to Run
1. Install Python 3
2. Download fintrack.py
3. Run: python fintrack.py
